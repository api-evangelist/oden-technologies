# Oden Technologies

> Oden Technologies provides AI-powered software for manufacturing optimization,
> delivering real-time, AI-driven recommendations to front-line operators to
> increase output, improve quality, decrease costs, and reduce downtime. The
> Oden Private Partner API (v2) is a RESTful API for reading, creating, and
> updating factory data on the Oden Platform: factories, lines, products,
> production intervals (runs/batches/states), scrap/yield, quality tests,
> metrics, targets, dashboards, and the Oden Query Language (OQL).

## APIs

- [Oden API v2 reference (Swagger UI)](https://api.oden.app/v2/ui/#/): Interactive reference for the 35-operation Private Partner API.
- [Oden API base URL](https://api.oden.app/v2): All access over HTTPS; JSON in/out; auth via `Authorization: Token <key>`.
